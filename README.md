# NOU'ER 诺尔香氛官网

## 项目简介

NOU'ER是专注于表现与价值的现代香氛品牌。本项目为NOU'ER品牌官方网站，展示产品系列、品牌故事和购买渠道。

## 本地开发

项目基于 Vite + React + TypeScript 构建。

### 环境要求

需要安装 Node.js 和 npm - [使用 nvm 安装](https://github.com/nvm-sh/nvm#installing-and-updating)

### 开发步骤

```sh
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

## 技术栈

本项目使用以下技术构建：

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## 可用命令

- `npm run dev` - 启动开发服务器（支持热更新）
- `npm run build` - 构建生产版本
- `npm run preview` - 预览生产构建
- `npm run lint` - 运行 ESLint 代码检查
```
